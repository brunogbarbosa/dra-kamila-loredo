# Dra. Kamila Loredo

Site editorial baseado no template Premium Vendas V3, com retratos reais, galeria de resultados, comparação interativa, navegação mobile e agendamento pelo WhatsApp.

## Desenvolvimento

Requer Node.js 20.9 ou superior.

```sh
npm ci
npm run dev
```

## Validação

```sh
npm run typecheck
npm run build
```

## Vercel

Importe este repositório na Vercel. O framework é **Next.js**, o diretório raiz é **./**, e os comandos padrão de instalação e build são suficientes. Não há variáveis de ambiente obrigatórias. A URL de produção é usada automaticamente nos metadados quando disponibilizada pela Vercel.

## Conteúdo

Dados e links em `data/site.ts`. O WhatsApp e a cidade foram obtidos na referência pública do Instagram fornecida pelo solicitante em 23/09/2026. Não foi informado registro profissional; esse campo fica vazio. Retratos e resultados foram fornecidos pelo solicitante. As fotos clínicas são preservadas sem retoques e otimizadas para WebP.

Fontes locais com as respectivas licenças em `public/fonts`. O favicon KL usa verde profundo, marfim e dourado envelhecido.
